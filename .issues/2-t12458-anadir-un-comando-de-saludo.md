## Objetivo

Crear un pequeño comando ejecutable con Node.js que muestre un saludo.

## Criterios de aceptación

- El comando se ejecuta con `node hello.js`.
- La salida es exactamente `Hola desde SolidKey AIDD`.
- Existe una prueba automática ejecutable con `node --test`.
- No se añaden dependencias externas.
- El README explica cómo ejecutar el comando y las pruebas.
